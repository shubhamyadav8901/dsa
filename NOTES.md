# NOTES

My own notes, in my own words. Written *after* understanding something, never
copied before.

Rule of thumb: if a note could have been written without having solved the
problem, it is not worth keeping.

Suggested shape for an entry:

```
### <Concept or pattern>
- What it is, in one sentence I'd say out loud
- When to reach for it (the trigger)
- Complexity
- The mistake I made the first time
```
