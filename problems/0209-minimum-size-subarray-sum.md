# Minimum Size Subarray Sum  (LeetCode 209 · Medium)

<https://leetcode.com/problems/minimum-size-subarray-sum/>

## Problem

Given an array of **positive** integers `nums` and a positive integer
`target`, return the length of the **shortest** contiguous subarray whose sum
is greater than or equal to `target`. If no such subarray exists, return `0`.

## Constraints

- `1 <= target <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`

## Examples

```
target = 7,  nums = [2, 3, 1, 2, 4, 3]   ->  2    ([4, 3])
target = 4,  nums = [1, 4, 4]            ->  1    ([4])
target = 11, nums = [1, 1, 1, 1, 1, 1]   ->  0    (no subarray reaches 11)
```
