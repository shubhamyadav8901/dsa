# Majority Element  (LeetCode 169 · Easy)

<https://leetcode.com/problems/majority-element/>

## Problem

Given an array `nums` of size `n`, return the majority element: the element
that appears **more than** `n / 2` times (rounded down). You may assume the
majority element always exists.

Follow-up: can you solve it in O(n) time and O(1) space?

## Constraints

- `n == nums.length`
- `1 <= n <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`
- A majority element always exists

## Examples

```
[3, 2, 3]              ->  3
[2, 2, 1, 1, 1, 2, 2]  ->  2
```

## Think

1. Give two simpler approaches and their time and space. What does each one
   waste that voting does not?
2. What does `candidate` hold before the first element is read? Does it
   matter?
3. Drop the guarantee: the input may have no majority. What does the voting
   pass return then, and how do you tell?
