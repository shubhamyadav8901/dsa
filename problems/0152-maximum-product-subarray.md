# Maximum Product Subarray  (LeetCode 152 · Medium)

<https://leetcode.com/problems/maximum-product-subarray/>

## Problem

Given an integer array `nums`, find a **non-empty** contiguous subarray that
has the largest product, and return the product.

## Constraints

- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- The product of any subarray of `nums` fits in a 32-bit integer

## Examples

```
[2, 3, -2, 4]   ->  6     ([2, 3])
[-2, 0, -1]     ->  0
[-2, 3, -4]     ->  24    (the whole array)
```
