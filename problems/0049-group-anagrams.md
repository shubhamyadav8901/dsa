# Group Anagrams  (LeetCode 49 · Medium)

<https://leetcode.com/problems/group-anagrams/>

## Problem

Given an array of strings, group together the strings that are anagrams of
each other. Return the groups in any order; the strings inside a group may
also be in any order.

## Constraints

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` consists of lowercase English letters

## Examples

```
["eat","tea","tan","ate","nat","bat"]  ->  [["bat"],["nat","tan"],["ate","eat","tea"]]
[""]                                    ->  [[""]]
["a"]                                   ->  [["a"]]
```
