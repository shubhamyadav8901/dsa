# Find All Duplicates in an Array  (LeetCode 442 · Medium)

<https://leetcode.com/problems/find-all-duplicates-in-an-array/>

## Problem

Given an integer array `nums` of length `n` where all the integers are in the
range `[1, n]` and each integer appears **at most twice**, return all the
integers that appear **twice**, in any order.

You must write an algorithm that runs in O(n) time and uses only O(1) extra
space. The returned list does not count as extra space.

## Constraints

- `n == nums.length`
- `1 <= n <= 10^5`
- `1 <= nums[i] <= n`
- Each element in `nums` appears once or twice

## Examples

```
[4, 3, 2, 7, 8, 2, 3, 1]  ->  [2, 3]
[1, 1, 2]                 ->  [1]
[1]                       ->  []
```
