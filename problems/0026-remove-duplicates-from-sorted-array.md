# Remove Duplicates from Sorted Array  (LeetCode 26 · Easy)

<https://leetcode.com/problems/remove-duplicates-from-sorted-array/>

## Problem

Given an integer array `nums` sorted in **non-decreasing** order, remove the
duplicates **in place** so that each unique value appears once, keeping their
relative order. Return `k`, the number of unique values.

The first `k` elements of `nums` must hold the unique values in order. What is
left beyond index `k - 1` does not matter.

## Constraints

- `1 <= nums.length <= 3 * 10^4`
- `-100 <= nums[i] <= 100`
- `nums` is sorted in non-decreasing order
- O(1) extra space

## Examples

```
[1, 1, 2]                        ->  k = 2, nums starts [1, 2]
[0, 0, 1, 1, 1, 2, 2, 3, 3, 4]   ->  k = 5, nums starts [0, 1, 2, 3, 4]
```
