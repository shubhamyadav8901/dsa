# Search Insert Position  (LeetCode 35 · Easy)

<https://leetcode.com/problems/search-insert-position/>

## Problem

Given a sorted array of **distinct** integers and a `target`, return the index
of `target` if it is present. If it is not, return the index where it **would
be inserted** to keep the array sorted.

You must write an algorithm with O(log n) runtime.

## Constraints

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` contains distinct values sorted in ascending order
- `-10^4 <= target <= 10^4`

## Examples

```
nums = [1, 3, 5, 6], target = 5   ->  2
nums = [1, 3, 5, 6], target = 2   ->  1
nums = [1, 3, 5, 6], target = 7   ->  4
```
