# problems/

One markdown file per problem: `NNNN-slug.md`, where `NNNN` is the LeetCode
number (zero-padded) — e.g. `0001-two-sum.md`, `0704-binary-search.md`.

Each file follows `templates/problem.md`: **Problem → Constraints → Examples →
Think**. The statement is restated in plain language with a link to the
original.

The `## Think` section is where the file stops. Hints, algorithms and solutions
do not belong here — hints are given in conversation, and solutions live in
`cpp/`, `py/` and `java/`.

These files are language-neutral on purpose: one problem, up to three
implementations.
